# COMPLETE ROUTE INVENTORY

## Overview
This inventory lists every **Next.js route** in the `app/` directory of the StreamVibe frontend, the corresponding **page component file**, and a brief description of its purpose. The project uses the **App Router** (Next.js 13+), so each folder with a `page.tsx` (or `page.jsx`) file represents a route. Nested folders map to dynamic routes.

---

## Notes
- Dynamic routes (`[param]`) are represented using bracket syntax as per Next.js conventions.
- All pages import shared components (e.g., `MediaCard`, `HeroBanner`, `Header`, `Sidebar`) located under `components/`.
- The admin area uses a dedicated `AdminLayout` (`app/admin/layout.tsx`) that wraps its child pages.
- Some routes (`/watch/[type]/[id]`) act as a catch‑all for media playback and delegate to more specific movie/series pages.
